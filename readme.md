# Portfolio

Personal portfolio built with plain HTML and CSS.


## Pages
- `index.html` – Home
- `hobbies.html` – Hobbies
- `skills.html` – Personal Skills
- `gallery.html` – Image Gallery
- `contact.html` – Contact

## Structure
```
portfolio/
├── index.html
├── hobbies.html
├── skills.html
├── gallery.html
├── contact.html
├── css/
│   └── style.css
├── images/
│   └── (Cupcake, Crochet, Reading, Baking, Resin, Painting .png)
└── README.md
```

## CSS techniques
- One external stylesheet (`css/style.css`) shared by every page
- `float` for side-by-side layouts, header, gallery and cards
- `clear` / `.clearfix` to contain floats
- Horizontal navigation menu
